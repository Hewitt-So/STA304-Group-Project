Assumptions for the one-sample binomial test

For the one-sample binomial test in RQ1, you list fixed trials and binary success as the assumptions. Those make sense, but there is one more check. For the normal approximation, np should be at least 5 and n(1-p) should be at least 5, where p is the hypothesized proportion. I would have accepted a numerical check of either condition, but you did not check them.

Chi-square test

I know you can proceed with the chi-square test of independence as if the assumption were not violated. There is an easy alternative, though, which is Fisher's exact test. I would prefer you use it.

Reporting with report::report()

I see you used report::report(), which I recommended in my document. It gives a nice rough draft, but you probably noticed that a lot of the text is repetitive, and you could have condensed it. For example, the output says effect sizes were labelled following Funder's (2019) recommendations. If you want to keep that sentence, elaborate on what those recommendations are. Your results include some significant effects and some that are not, and it is fine to report which is which. When the text is nearly the same each time, though, readers skim it faster, so some editing to make it less repetitive would be easier to read.
